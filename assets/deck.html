The solution

A vault with a progression system.

  • Deposit MUSD and receive bMUSD receipt shares, 1:1, with no lock-up.
  • Yield accrues every second on your position, paid from MUSD the vault already holds.
  • Cross a milestone and the vault mints an ERC-721 achievement badge — collectible, on-chain.
  • The interface shows progress toward the next badge at all times, so saving feels active.
  • Badges are rendered from the contract itself: each one is an SVG generated on-chain.

How it works

Yield that cannot outrun the vault.

deposit(a)
  ├─ pull a MUSD, mint a receipt shares 1:1
  └─ reward index starts accruing

index += ratePerSecond × elapsed
pendingYield = shares × (index − snapshot)

withdraw()
  ├─ pay principal + accrued yield
  └─ burn receipt shares
  • Buffer-backed payouts. Yield is paid from MUSD the vault holds above principal, so payouts are always coverable.
  • Deposits always fully backed. assets ≥ principal after every operation.
  • No owner withdrawal path. The owner sets the rate, funds the buffer and pauses — nothing else.
Wave 1 note

The rate is owner-controlled so the demo can show accrual on camera. The UI labels it as a demo rate — it is never sold as a real APR.
